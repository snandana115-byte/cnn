IMAGE-CLASSIFICATION-WITH-CNN
🧠 CIFAR-10 Image Classification with CNN

A simple and interactive Streamlit web application that uses a trained Convolutional Neural Network (CNN) model to classify images into one of the 10 CIFAR-10 categories.

🚀 Features
📸 Upload an image (JPG, PNG, JPEG)
🤖 Predicts image class using trained CNN model
📊 Displays prediction confidence
📉 Shows probability distribution for all classes
⚡ Fast and user-friendly interface
🧩 Classes (CIFAR-10)
The model predicts one of the following 10 classes:

Airplane ✈️
Automobile 🚗
Bird 🐦
Cat 🐱
Deer 🦌
Dog 🐶
Frog 🐸
Horse 🐴
Ship 🚢
Truck 🚚
🛠️ Tech Stack
Python 🐍
TensorFlow / Keras
Streamlit
NumPy
PIL (Python Imaging Library)
